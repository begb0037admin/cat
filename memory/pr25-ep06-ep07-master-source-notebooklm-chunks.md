Kevin caught that `EP06_G-Zero_Control/notebooklm/EP06_NotebookLM_Chat_Chunks.md` and `EP07_The_Empires_of_AI/notebooklm/EP07_NotebookLM_Chat_Chunks.md` were both still the untouched blank template, byte-identical (modulo CRLF) to `EPISODE_FOLDER_TEMPLATE`'s copy — expected, since Content Briefs (PR #21, merged) had only just been approved, but the next real production step per `PRODUCTION_PROCESS.md` (Master Source → NotebookLM prompt) had never actually happened. Result: **PR https://github.com/begb0037admin/ai-news-channel/pull/25** (branch `cat/ep06-ep07-master-source-notebooklm-chunks` off `main`), open, not yet merged.

**What's in it, six files total:** `sources/EP06_Master_Source.md` and `EP07_Master_Source.md` (self-contained evidence prose, matching `EP05_Master_Source.md`'s actual structure — a permanent Show Rules block copied verbatim, then narrative episode content — not the generic template's section-header shape, same "follow the real example not the generic template" pattern as `memory/pr21-ep06-ep07-content-briefs.md`); `notebooklm/EP06_NotebookLM_Chat_Chunks.md` and `EP07_NotebookLM_Chat_Chunks.md` (the real four-part instruction set); and `notebooklm/EP06_Audio_Overview_Prompt.md` and `EP07_Audio_Overview_Prompt.md` (the fuller companion doc — EP05 has this file too, not just the chunks file, and EP06/EP07's copies were likewise still blank template, confirmed by diffing against the template before assuming it needed building).

**Confirmed blank-vs-real check method:** `diff` against `EPISODE_FOLDER_TEMPLATE`'s equivalent file returned differences for some files that were visually identical when read — turned out to be CRLF (episode folder) vs LF (template) line-ending only, confirmed via `xxd`/`wc -c` byte comparison, not real content differences. Worth checking this before concluding a file has "real" content just because a naive `diff` shows a delta — a byte-level check settles it. All six target files were confirmed genuinely blank (LF/CRLF aside) before writing anything.

**Character-limit verification, not eyeballed:** wrote a small Python script splitting each chunks file on its `## Part N of 4` headers and counting characters per block, rather than trusting a visual read. All eight blocks (four per episode) came in well under the 2,700-character limit — max was 1,865 (EP07 Part 3). Worth doing this programmatically any time a task has an explicit numeric constraint like this; eyeballing prose length is unreliable.

**Judgment call — Master Source follows the approved Content Brief's claim selection, not every `Featured`-tagged Research Ledger claim.** Both EP06 and EP07's Research Ledgers (`memory/ep06-ledger-show-fit-field.md`, `memory/ep06-ep07-notebooklm-source-pass-pr18.md`) tag more claims `Featured` than either approved Content Brief (PR #21) actually selected for its "Mechanism, In Order" list — e.g. EP06's Lehdonvirta *Cloud Empires* (Claim 014) and the Kokotajlo/Bremmer GZERO crossover (Claim 031) never made it into the Content Brief's own arc; EP07's Mejias & Couldry *Data Grab* (Claim 020) likewise. Since the Content Brief is Kevin's own already-approved editorial narrowing of ~35/~22 claims down to the ~8-10 that carry a ≤20-minute episode (`HANDOVER.md`'s own framing of that task), I treated the Content Brief as authoritative and didn't layer in additional Featured claims it hadn't chosen — flagged explicitly in the PR body rather than quietly expanding scope. Worth remembering: "build the Master Source around Featured claims" and "build the Master Source from the approved Content Brief" can point at different, narrower sets — when they conflict, the Content Brief wins, since it's the later, more specific approval.

**Judgment call — EP06's closing runway forces continuity to EP05 (a real sequential follow-on); EP07's does not force continuity to EP06.** EP06's Content Brief explicitly writes the EP05 callback into its own Conversation Arc, so the Master Source/chunks close ties back to EP05 directly, matching EP04→EP05's pattern. EP07 opens with a brief EP06 callback (per its own Content Brief) but its close resolves on its own terms — the "empire" label question, landing on live Open Markets/Amnesty/DOJ monopoly-breakup advocacy — rather than manufacturing a false link back to EP06's sovereignty argument, since EP06/EP07 are siblings split from one original ledger (`memory/ep06-split-into-ep06-ep07-ep08-renumber.md`), not a strict sequential pair.

**Method:** fresh clone into scratchpad (confirmed the persistent local clone at `C:\Users\admin\ai-news-channel` was stale — last commit 14 June vs. `main`'s actual HEAD from 7 August, over 50 commits behind), single branch, six independent file edits via `git add`/commit/push (not the Contents API this time — a full local clone was already needed to diff against the template byte-for-byte, so plain git was more direct than six separate API PUTs). `gh pr create` needed `--repo`, `--base`, and explicit `--head` flags — a plain `gh pr create` immediately after `git push -u` failed with "you must first push the current branch to a remote" even though the push had visibly succeeded and `git branch -vv` showed no tracking ref recorded; the explicit flags worked on the first retry. Worth trying explicit `--head`/`--repo`/`--base` flags if `gh pr create` claims a pushed branch isn't pushed.
